# 地球 online 学习规划

仅固定工作台所有者（且仍为管理员）可访问 `/admin/workbench` 及其目录、档案、海报、计划与接口。左侧菜单只切换面板；桌面固定整体高度，目录及对话可在面板内滚动。

## 首次使用

1. 课程目录：导入已核验教材草稿，或上传 PDF、图片、文本、JSON。PDF 使用本地 PDF.js 提取文字；扫描 PDF 可以转换为图片后使用配置的视觉模型，或手动粘贴。图片识别会将图片发送给本人配置的服务，结果始终为待确认草稿。
2. 核对科目 → 章节 → 知识点、稳定 ID、来源和规划参数。保存修订草稿，再选择该保存版本确认用于排课。新版本显示增加、移除与修改；学习记录保留。
3. 学习条件：核对院校专业、时间预算、基础、优先级及休息日，确认保存并启用排课。默认预算与耗时是明确标注的假设，不能代表真实作息。
4. 生成今日及14天计划。每日最多三项，预留缓冲，拆分较长任务。未来计划只是推演；完成时填写实际耗时、掌握情况与错因，自动重新评估未锁定的未来安排。
5. Agent 设置支持 Chat Completions 工具调用服务，填写 HTTPS Base URL、模型与密钥，测试连接。消息创建调整预览，点击应用才写入；只能撤销最近一次调整且其后未发生计划或设置变更。已完成和已锁定任务不能被 AI 修改。

## 运行与安全

迁移 `drizzle/0010_study_planner.sql` 为增量表，不删除旧任务或文件。上线前备份数据库，在生产数据副本上应用迁移并验收。生产入口 `scripts/start-production.mjs` 启动独立每分钟执行器；到北京时间设置的生成时间后补齐计划，不依赖打开页面。每日计划有用户/日期唯一键，数据库修订号防止并发覆盖。

生产程序首次启动在私有卷 `/data/secrets/study-agent.key` 生成加密密钥（权限600），以 Worker secret `STUDY_AGENT_ENCRYPTION_KEY` 注入。API Key使用AES-GCM加密，前端只收到末四位掩码。必须连同数据库备份保留该加密密钥，否则旧凭证无法解密。服务地址需HTTPS公开域名，校验公共DNS地址并拒绝重定向。不能通过公网HTTP保存API Key；可以使用HTTPS，或 `ssh -L 8788:127.0.0.1:80 root@服务器地址` 后在 `http://localhost:8788` 配置。

未配置AI时仍可自动排课，本地规则支持时间预算减负预览，并明确标记未调用AI。AI故障保留原计划。所有者的完整档案（包括财务）不自动发送给模型；上下文包含本人主动填写的学习条件、目录、进度与近期计划。不要向对话发送凭证。

测试：`node scripts/test-study-planner.mjs`。上游工具调用通过隔离模拟服务验证；实际服务连接需本人配置API Key后测试。私人档案部署数据只放在忽略的私有文件中；`scripts/seed-study-profile.py` 保留前一版本并仅首次导入，不覆盖后续本人编辑。
